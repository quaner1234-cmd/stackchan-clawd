# 中国大陆放假调休表

`china-workdays.json`依据国务院办公厅年度通知记录放假区间和补班日；其余日期按周一至周五工作、周末休息处理。2026年来源：国办发明电〔2025〕7号，2025-11-04；原通知由中国政府网国务院公报发布，链接在JSON中。2026-10-18已核对全文，原始抓取保留于项目`.firecrawl/workdays-2026.json`。

这是国务院统一放假调休安排，不代表特定单位的值班或轮班表。运行时只读本机，不请求收费或第三方节假日API。

当前仅收录2026年。尚未取得2027年官方年度安排，不使用预测日历；未知年份停止叫醒并在家长窗口提示更新，聊天等功能继续可用。

## 更新方法

在`years`中添加有官方出处的一年，并同时记录`source_title`、`source_date`、`source_url`；核对全部放假区间和补班日期，然后运行：

```powershell
python ../test_workday_alarm.py
```

不将前一年的日期套用到下一年。
